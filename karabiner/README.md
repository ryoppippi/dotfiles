# my personal karabiner config

My personal karabiner config built with [karabiner.ts](https://github.com/evan-liu/karabiner.ts)

## Build

`karabiner.json` is generated by Nix and linked into `~/.config/karabiner`:

```bash
nix run .#switch
```

To preview the generated rules without touching the live config:

```bash
bun install
bun run check
```
